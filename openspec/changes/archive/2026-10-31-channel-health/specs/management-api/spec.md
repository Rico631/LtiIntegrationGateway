# Spec Delta

## ADDED Requirements

### Requirement: Состояние канала доступно через управляющий API

Управляющий API SHALL возвращать состояние канала: наличие активной ревизии и её номер, признак
настроенного секрета и имя ключа конфигурации без значения, срок действия клиентского сертификата,
последние ошибки обмена и время проверки. Значение секрета, тела сообщений и авторизационные
заголовки SHALL в ответ не попадать. Неизвестный канал SHALL возвращать `404` (`NotFound`).

#### Scenario: Канал с активной ревизией

- **WHEN** запрашивается состояние канала с активной ревизией
- **THEN** ответ содержит номер активной ревизии, состояние `ACTIVE`, признак секрета, срок
  сертификата (если тип авторизации `client_certificate`) и последние ошибки

#### Scenario: Секрет не настроен

- **WHEN** активная ревизия требует секрет, а значение по ключу конфигурации отсутствует
- **THEN** признак настроенного секрета равен `false`
- **AND** ответ содержит имя ключа конфигурации без значения

#### Scenario: Канал без активной ревизии

- **WHEN** у канала нет активной ревизии
- **THEN** ответ имеет статус `200` и состояние `NO_ACTIVE_REVISION`
- **AND** номер активной ревизии равен `0`

#### Scenario: Неизвестный канал

- **WHEN** запрашивается состояние незарегистрированного канала
- **THEN** ответ имеет статус `404` (`NotFound`)

#### Scenario: Истёкший клиентский сертификат

- **WHEN** активная ревизия использует `client_certificate`, а срок действия сертификата истёк
- **THEN** признак настроенного секрета равен `false`
- **AND** срок действия сертификата присутствует в ответе для диагностики
- **AND** значение материала и пароля отсутствует

#### Scenario: Последние ошибки

- **WHEN** в журналах есть ошибки обмена по каналу
- **THEN** ответ содержит не более пяти последних ошибок по каждому направлению
- **AND** каждая ошибка содержит время, направление, код ошибки и HTTP-статус для исходящих
- **AND** тела сообщений и заголовки авторизации отсутствуют

#### Scenario: Чтение фиксируется в аудите

- **WHEN** состояние канала запрашивается через управляющий API
- **THEN** аудит содержит операцию чтения состояния с каналом и результатом
- **AND** значения секретов в аудите отсутствуют
