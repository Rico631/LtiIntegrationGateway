# Spec Delta

## ADDED Requirements

### Requirement: Секреты активной конфигурации проверяются при старте

Перед началом обслуживания запросов шлюз SHALL проверять секреты всех активных ревизий каналов и
активных версий контрактов. Для типов авторизации, требующих секрет, отсутствие значения или
непригодный материал клиентского сертификата SHALL завершать запуск ошибкой с перечнем имён ключей
конфигурации без значений. Конфигурации вне состояния `Active` SHALL NOT блокировать запуск.

#### Scenario: Секрет отсутствует

- **WHEN** активная ревизия канала требует секрет, а значение по ключу конфигурации отсутствует
- **THEN** запуск завершается ошибкой
- **AND** сообщение содержит имя ключа без значения
- **AND** шлюз не начинает обслуживать запросы

#### Scenario: Все секреты настроены

- **WHEN** все активные ревизии и версии контрактов обеспечены секретами
- **THEN** запуск продолжается
- **AND** шлюз обслуживает запросы

#### Scenario: Черновик без секрета

- **WHEN** черновик канала или версии контракта не имеет секрета
- **THEN** запуск не блокируется
