# Spec Delta

## ADDED Requirements

### Requirement: Публикация канала предупреждает об отсутствующем секрете

Публикация ревизии канала SHALL оставаться успешной при отсутствии секрета, но SHALL возвращать
предупреждение с кодом `secret_key_missing` и именем ключа конфигурации без значения.

#### Scenario: Секрет не настроен

- **WHEN** публикуется ревизия с типом авторизации, требующим секрет, а значение отсутствует
- **THEN** публикация считается успешной
- **AND** ответ содержит предупреждение `severity = WARNING` и имя ключа конфигурации
- **AND** значение секрета в ответе отсутствует

#### Scenario: Секрет настроен

- **WHEN** публикуется ревизия, для которой секрет настроен или не требуется
- **THEN** ответ не содержит предупреждения об отсутствующем секрете
