# Spec Delta

## ADDED Requirements

### Requirement: Настройки версии контракта управляются через API

Управляющий API SHALL отдавать настройки версии контракта и SHALL позволять изменять их для
черновика: очередь получателя, тип авторизации с несекретными параметрами и квоту частоты.
Изменение опубликованной версии SHALL отклоняться, отсутствие версии SHALL возвращать `404`
(`NotFound`), неверный тип авторизации — проблему с кодом `auth_type`.

#### Scenario: Чтение настроек

- **WHEN** запрашивается версия контракта канала
- **THEN** ответ содержит очередь получателя, тип авторизации, имя заголовка или пользователя,
  ключ конфигурации и квоту частоты
- **AND** значение секрета в ответе отсутствует

#### Scenario: Изменение черновика

- **WHEN** для черновика задаются очередь получателя и тип авторизации `basic`
- **THEN** операция завершается успешно
- **AND** повторное чтение возвращает новые значения

#### Scenario: Изменение опубликованной версии

- **WHEN** настройки изменяются для опубликованной версии
- **THEN** ответ содержит проблему с кодом `version`, настройки не меняются

#### Scenario: Неверный тип авторизации

- **WHEN** задаётся тип авторизации вне набора `none`, `api_key`, `basic`, `client_certificate`
- **THEN** ответ содержит проблему с кодом `auth_type`

#### Scenario: Неизвестная версия

- **WHEN** запрашивается версия, которой нет у канала
- **THEN** ответ имеет статус `404` (`NotFound`)
