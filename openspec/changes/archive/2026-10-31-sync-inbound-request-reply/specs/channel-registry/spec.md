# Spec Delta

## ADDED Requirements

### Requirement: Направления каналов независимы

Система SHALL хранить outbound- и inbound-каналы как независимые сущности с собственными
идентификаторами и жизненным циклом. Один и тот же `channel_name` MAY существовать в обоих
направлениях; общий канал с двумя направлениями SHALL NOT создаваться.

#### Scenario: Совпадающие имена

- **WHEN** создаётся outbound-канал `bank-a` и inbound-канал `bank-a`
- **THEN** существуют две независимые записи
- **AND** изменение одной записи не изменяет другую

#### Scenario: Попытка создать двунаправленный канал

- **WHEN** запрос пытается создать канал с направлением `BOTH`
- **THEN** запрос отклоняется как некорректный
- **AND** новые записи не создаются

### Requirement: Outbound-канал не содержит OpenAPI-контракт

Outbound-канал SHALL содержать только настройки исходящих HTTP-вызовов и SHALL NOT принимать
OpenAPI-документ. Контракты SHALL быть доступны только для inbound-канала.

#### Scenario: Создание outbound-канала

- **WHEN** создаётся outbound-канал без OpenAPI-документа
- **THEN** создаётся канал с черновиком ревизии
- **AND** контракт у канала отсутствует

#### Scenario: Контракт для outbound-канала

- **WHEN** для outbound-канала пытаются загрузить или активировать OpenAPI-контракт
- **THEN** операция отклоняется
- **AND** конфигурация outbound-канала не меняется
